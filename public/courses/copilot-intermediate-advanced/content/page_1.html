Module 1: Prompts and agents

Estimated time: 9-10 minutes

Objective: Understand the difference between a prompt, an agent, and a workflow.

Introduction

Imagine someone pasted a programme’s National Student Survey comments into Copilot and explained what they wanted: a report that categorised student comments into four themes, condensed into a summary for each theme, and a rule about never naming staff.

Now imagine you'd like to do the same task - would you prefer writing the prompt again (and trying to write a prompt from scratch), or clicking a button and it just starts?

The 'clicking a button' option is where agents come in!

Definitions: Prompts, Agents and Workflows

A prompt is an instruction you type into a chatbox in an AI like Copilot. You give the context every time - attach any documents needed, give the background, explain what you'd like done and what good looks like.

An agent is a saved, expanded prompt. An agent has saved your instructions (an expanded, detailed prompt), knows where your files are (and can access them), and can run any time when you ask it to, or on a schedule (or even when something changes in a file). No saving prompts, or trying to remember them.

A workflow is a process that you’ve broken into steps and linked together. Those steps can be an agent, a person, or even something else, like a Power Automate automation. You can set the rules about when it starts and stops.

For example, here's what the that NSS report task might look like as a prompt, an agent and a workflow:

Level

The NSS report as…

What you still do by hand

Prompt

Attach the file, explain the job, read the answer

Everything, every year

Agent

The rules, the report template, and last year’s report written in once

Check the draft and write the recommendations

Workflow

It starts, an agent drafts, a second agent checks the draft, a person approves, and then it's emailed to SLT and saved in Sharepoint

Decide when and how it starts. Also approve, if you're the designated human in the loop.

Should you use a prompt or an agent?

A task worth moving from a prompt to an agent usually has three things:

  1. It comes round regularly

  2. It uses the same or similar files each time

  3. The rules for doing it don’t change

The NSS report example has all three: it comes round every summer, it draws on the same feedback file, report template, and last year’s report, and its rules don’t change from one year to the next.

Any more examples?

If you're struggling to think of any more tasks that could be agents, here are some ideas for agents that could be useful:

If you deliver projects and programmes:

  • Track the actions from each week’s project meeting: what’s open, what’s overdue, and what’s closed since last week.

  • Draft a new project’s scope, milestones, and dependencies from the approved business case, with every line citing its paragraph.

  • Turn a month of project updates into the highlight report.

If you manage dashboards or administer projects:

  • Pull the same fields from every project’s return into one dashboard view.

  • Check each submission against the template before it reaches a board, and list what’s missing.

  • Draft the covering note for a meeting pack from the papers already in the folder.

If you work in planning and analytics:

  • Give the week’s admissions position against target and against the same point last cycle.
  • Run the same check on every faculty planning submission against the planning guidance.
  • Theme a survey’s free text against a fixed framework, so this year can be compared with last.

Activity: Test a prompt

Download the NSS 2026 Free Text and Scores workbook then open Copilot and sign in with your work account.

NSS 2026 Free Text and Scores workbookExcel · 15 KB

Attach the workbook and paste in the prompt below. This gives Copilot three things: the role to take, the context it needs, and the task.

You’re a student surveys analyst at a UK university. The attached workbook holds one programme’s National Student Survey responses, with scored questions and a free-text column. Theme the free-text comments against four themes and no others: teaching and learning, assessment and feedback, organisation and management, and learning resources. For each theme, give the number of responses, a one-line summary, and one comment quoted word for word. Put the four themes in a table.

The result should be a table with four rows, counts, and quotes. Check it against three points:

  1. Does any quote name a member of staff? Four comments in the file do.

  2. Has a student’s comment about their learning support plan been counted as a learning resources complaint, or summarised into a line?

  3. Has a fifth theme appeared, such as student voice?

Note: the prompt didn’t include the rules that make this report safe to circulate: never name staff, keep accessiblity needs out of the counts, etc.

Reflection:

Think of one job you do on a cycle, weekly or monthly basis, where you explain the same thing to Copilot each time. Write your answers to these three questions:

  1. What’s the job, and what do you have to explain every time you run it?

  2. Which files or folders does it always draw on?

  3. Is there anything it must never do, and have you ever had to correct it for doing it?
